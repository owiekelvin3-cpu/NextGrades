# NextGrades - Premium SaaS Education Platform

A world-class premium SaaS education platform built with Next.js, Tailwind CSS, and Framer Motion.

## 🚀 Features

### Public Website
- **Cinematic Landing Page** - Premium hero with animations
- **Programs Page** - 1:1, Group, and Matura Excellence programs
- **Subjects Page** - Mathematics, English, German, Physics, etc.
- **Pricing Page** - Premium plans with monthly/yearly toggle
- **Contact & Support** - Premium contact forms and FAQ

### Dashboards
- **Student Dashboard** - Upcoming lessons, courses, progress tracking
- **Teacher Dashboard** - Student management, resource upload, AI quiz generator
- **Admin Dashboard** - Full platform management

### Special Features
- **Language Switcher** - English and German support
- **AI Quiz Generator** - Futuristic AI generation interface
- **Responsive Design** - Perfect on desktop, tablet, and mobile
- **Premium UI** - Apple/Linear inspired design

## 🛠️ Tech Stack

- **Next.js 16** - Full-stack React framework
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **Lucide React** - Beautiful icons
- **Vercel** - Deployment platform

## 📦 Installation

```bash
npm install
```

## 🚀 Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## 🏗️ Build

```bash
npm run build
```

## 📁 Project Structure

```
/app                  - Next.js App Router
/components            - Reusable components
  /ui                  - UI components (Button, Card, Input, Badge)
  /dashboard           - Dashboard components (Sidebar)
/lib                  - Utility functions
```

## 🔗 Deployment

This project is ready for Vercel deployment!

1. Connect your GitHub repository to Vercel
2. Vercel will automatically detect it's a Next.js project
3. Deploy! 🚀
